# Financial Time Series

**M.S. Data Analytics & Visualization — Yeshiva University, Katz School of Science and Health**

## Course Description

This course explores the analysis and modeling of financial time series data. Topics include stationarity, ARIMA models, GARCH volatility modeling, cointegration, and forecasting techniques applied to financial markets and economic indicators.

## Repository Structure

- `notebooks/` — Jupyter notebooks with analysis and modeling exercises
- `assignments/` — Homework and problem sets
- `data/` — Financial datasets and market data
- `reports/` — Written reports and findings
- `Time-Series-Fundamentals_v2.pdf` — Core reference material

## Tools & Technologies

- Python
- Pandas, NumPy, Statsmodels
- Matplotlib, Seaborn, Plotly
- Scikit-learn
- Jupyter Notebooks
